# Tejas Deo — Portfolio (React + Tailwind)

## What this is
This is a ready-to-deploy React + Tailwind portfolio for **Tejas Deo** with:
- Dark mode toggle (persistent via localStorage)
- `Download Resume` button linking to `/Tejas_Deo_Backend_Engineer.pdf`
- Preconfigured `gh-pages` deploy script and `homepage` in package.json

## Quick start (locally)
1. Unzip the project
2. `npm install`
3. Place your resume PDF at `public/Tejas_Deo_Backend_Engineer.pdf`
4. `npm run deploy`  (deploys to GitHub Pages)

Make sure your repository is named `tejas-portfolio` and remote origin set to `https://github.com/tejas-deo/tejas-portfolio.git`

## Notes
- Tailwind is configured. If you prefer to use plain CSS, replace `src/index.css`.
- The `homepage` field already points to: `https://tejas-deo.github.io/tejas-portfolio`
